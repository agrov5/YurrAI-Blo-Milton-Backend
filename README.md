This is the backend for the AI on the number of (Call +1 (289) 429-0380 (Canada Number)), the backend acts as a middleman to connect the appointment scheduling tool with the AI LLM. 

This whole process can be boiled down to a simple pipeline

STT -> LLM (+Tool Calls) -> TTS, where the user talks which gets converted to text and then text to text happens via LLM and then gets relayed back to user.
